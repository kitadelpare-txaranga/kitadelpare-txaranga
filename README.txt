KITADELPARE TXARANGA - WEBGUNEA

Webgune estatiko eta doakoa. Fitxategi guztiak ZIP honen barruan daude.

ARGAZKIAK ETA LOGOA
- assets/logo-kitadelpare.png eta assets/logo-kdp.png: bidalitako jatorrizko logotipoak.
- assets/originalak/: bidalitako argazki originalak eta jatorrizko logoaren PDFa.
- assets/kartela-*.jpg: aurreko webguneko kartel-irudiak.

ARGITARATZEA (DOAN, GitHub Pages erabiliz)
1. Sortu GitHub kontu bat.
2. Sortu repo publiko bat: kitadelpare.github.io
3. Igo ZIP honetako fitxategi guztiak repoaren erro karpetara (index.html, style.css, script.js, README.txt eta assets karpeta).
4. Settings > Pages > Deploy from a branch aukeratu; main eta /(root) hautatu; Save.
5. Webgunea https://kitadelpare.github.io helbidean argitaratuko da.

Ez da ordainpeko hostingik edo domeinurik behar helbide hori erabiltzeko.
